## What is on it

- **Work:** product and operations roles, most recent first.
- **Product case studies:** the SportsHedge MVP, the Open IIT case (1st of 16) and an AI product review, each linked to its full write-up.
- **AI and data-science work:** competition results and ML projects, each linked to its code.
- **Athletics, toolkit and contact**, with a resume download.

## How it is built

One static page (`index.html`) with inline CSS and JavaScript, published by GitHub Pages from the `main` branch. There is no build step and no framework. Fonts load from Google Fonts, and visits are counted with GoatCounter, which sets no cookies.

## Updating it

1. Edit `index.html` for content, or replace files in `assets/` (portrait, share image, resume PDF).
2. Open `index.html` in a browser and check it at desktop and phone widths.
3. Commit and push to `main`. GitHub Pages publishes the change in a minute or two.
